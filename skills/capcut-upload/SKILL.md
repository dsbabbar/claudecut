# Upload media to CapCut

**Not available yet.** claudecut's uploader is still being built.

Until it ships:

- Tell the user that local file uploads are not supported yet in this version of claudecut.
- Offer workarounds that need no upload:
  - Template search accepts a public `http(s)` image URL directly.
  - Generation and captions can use media already in the user's CapCut account if they can provide its `vid`.
- Do not upload through the CapCut website, the desktop app or browser automation instead.
